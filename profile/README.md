## Our Story

저희는 소프트웨어공학 수업을 함께 들으며 친해졌습니다. 팀 프로젝트를 같이 하면서 개발 이야기부터 과제와 리포트에 대한 고민까지 자연스럽게 나누는 사이가 되었고, 언젠가 대학생이 실제로 겪는 불편을 해결하는 서비스를 만들어 보자는 이야기를 종종 하곤 했습니다.

그러던 중 카카오의 PlayMCP를 알게 되었고, 아이디어를 실제 서비스로 만들어 사용자에게 선보일 수 있는 좋은 기회라고 생각해 함께 지원하게 되었습니다.

주제를 고민하면서 저희가 주목한 것은 가장 가까운 문제였습니다. 글을 대신 써주는 AI는 많지만, 학생이 직접 쓴 리포트를 제출 전에 점검해 주는 도구는 부족했습니다. 저희도 과제를 낼 때마다 분량, 문서 구조, 인용, 참고문헌을 여러 서비스에서 따로 확인해야 했고, 이 불편을 한 곳에서 해결하기 위해 **Report Guard**를 개발했습니다.

## Report Guard

리포트 제출 전 점검을 돕는 MCP 서비스입니다.

| 구분 | 내용 |
| --- | --- |
| 대상 | 리포트와 과제를 작성하는 대학생 |
| 주요 기능 | 분량, 문서 구조, 인용, 참고문헌, 표절 위험 신호 점검 |
| 방향 | 과제를 대신 작성하지 않고, 학생이 직접 쓴 글을 스스로 검토하고 보완하도록 지원 |

## Why PlayMCP

Report Guard는 저희가 직접 겪은 불편에서 출발했습니다. 이번 공모전을 통해 실제 대학생에게 서비스를 공개하고, 사용자 의견과 Kakao Tools를 반영해 더 실용적인 대학생 지원 서비스로 발전시키고자 합니다.
