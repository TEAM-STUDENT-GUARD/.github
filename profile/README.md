# Student Guard

> AI가 대신 써주는 시대, 우리는 학생이 직접 쓴 글을 지킵니다.
> 대학생이 직접 작성한 결과물을 제출 전에 점검하고 완성도를 높일 수 있도록 돕는 LLM 서비스를 만듭니다.

## Our Story

>

저희는 소프트웨어공학 수업에서 팀 프로젝트를 함께 진행하며 친해졌습니다. 프로젝트를 준비하는 과정에서 학교생활에 대한 이야기를 자주 나눴고, 과제 제출 기한이나 분량, 형식 같은 조건을 놓쳐 다시 확인하고 수정했던 경험도 공유했습니다. 이러한 불편을 조금이라도 줄여보자는 생각으로 대학생을 위한 서비스를 함께 만들어 보기로 했습니다.

그러던 중 카카오의 PlayMCP를 알게 되었고, 평소 나누던 아이디어를 실제 서비스로 구현해 사용자에게 선보일 수 있는 좋은 기회라고 생각해 함께 지원하게 되었습니다.

서비스 주제를 고민하며 가장 먼저 주목한 것은 저희가 반복해서 겪어 온 문제였습니다. 글을 대신 작성해 주는 AI 서비스는 많지만, 학생이 직접 작성한 리포트를 제출 전에 종합적으로 점검해 주는 도구는 부족했습니다. 과제를 제출할 때마다 분량, 문서 구조, 인용 표기, 참고문헌 등을 여러 서비스에서 각각 확인해야 했습니다.

이러한 불편을 하나의 서비스에서 해결하고자 리포트 제출 전 점검을 돕는 MCP 서비스 **Report Guard**를 개발했습니다.
